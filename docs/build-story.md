## The honest parts

**The engine is deterministic-first.** The core suite — article-style show
notes, discussion kit, 5-day email series, social pack, summary, titles — is
generated by extractive logic (theme ranking, sentence selection, verbatim
quote anchoring) with zero API keys. An LLM pass enhances prose when a key is
present, but every quote/anchor must validate as an **exact substring of your
transcript** or that artifact silently falls back to deterministic. This is
enforced in code and tested (`engine/test.js`, `api/license.test.js`): a
paraphrased quote is rejected even when it differs by one word. The tests even
verify tolerance for LLM punctuation habits (curly quotes, ellipses) so real
verbatim quotes aren't falsely rejected.

**A pivot happened on day 7, and it's in the history.** The original vertical
was churches (best verified pricing, $39–129/mo incumbents). The owner set a
hard constraint — no religious-domain products — so the entire product was
repositioned to podcasters in a single session: new artifacts, new demo, new
branding, and a permanent test gate asserting religion-free output. The old
logs stay, unedited (except redacting infrastructure account IDs).

**The numbers are not impressive (yet) — and they're logged anyway.**
`docs/METRICS.md` records $0 revenue and zero real users at the time of
writing, because distribution is gated on platform accounts only the owner can
create. The map at /map shows all of this live, including what's blocked on
whom.

**What the agent can't do:** create accounts (Lemon Squeezy, Product Hunt,
Hacker News, Google Search Console), hold API keys, or sign anything. Those
are the red chips on the map. Everything else — build, test, deploy, monitor,
write, narrate, compose video — ran without a human in the loop.

## Why "verbatim quotes" is the whole product

Research on day 1 surfaced the same complaint across every AI content tool:
*the output invents things, and users end up rewriting it.* For podcast
content the sharpest form is fabricated "quotes" attributed to real guests —
relationship poison. So the constraint became architectural: the generator
literally cannot emit a quote that isn't in your transcript. That's a
deterministic engine underneath, a substring validator on every AI artifact,
and a fallback that fires per-artifact. Boring engineering, honest output.
