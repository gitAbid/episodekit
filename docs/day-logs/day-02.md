## What shipped
1. **Sermon engine core** (`engine/`):
   - `lib.js` — deterministic suite builder, pure ESM, zero deps. From transcript:
     titles (6), extractive summary (~150 words), edited manuscript with movement
     headings, discussion guide (quote-anchored), 5-day devotional series, social
     pack (pull quotes + captions + ≤280-char X posts). Whitespace-normalized
     source of truth (`normalizeWs`) so every quote is a verbatim substring.
     Heuristics tuned: sermon meta-language stopworded, liturgy opening excluded
     from quotes, possessive themes merged, movement labels deduped.
   - `glm.js` — GLM chat-completions path. **Honesty validator**: AI-returned
     quotes must be verbatim substrings of the sermon or the artifact falls back
     to deterministic. Any AI failure → deterministic suite, never a user error.
   - `index.js` / `cli.js` — orchestrator + CLI with `--json/--md/--html`
     renderers. `package.json` (type:module, `npm test`, `npm run sample`).
2. **Demo sermon** — `docs/samples/demo-sermon.txt`: original 741-word expository
   sermon (Prodigal Son), dedicated **CC0** in-file.
3. **Committed sample suite (marketing proof)** — generated by the engine, no
   manual edits: `docs/samples/sample-suite.json`, `sample-suite.md`, and
   `site/samples.html` (rendered, dark-theme, linked from landing nav + hero).
   Output quality: title "Father — House", titles incl. "The Father We Keep
   Avoiding", movement headings "Running / House / Outside", 5 devotional days.
4. **API** — `api/generate-suite.js` gains `mode:"full"` → engine suite (works
   keyless, GLM-enhanced when key set); discussion-guide mode unchanged.
